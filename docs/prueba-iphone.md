# Prueba en iPhone

Hacela con el link publicado, antes de pasársela a tus amigos. Anotá lo que falle.

## 1. Armar el atajo (una sola vez, lo hacés vos)

En la app **Atajos**, creá un atajo nuevo llamado **Frase del día** con estas acciones, en orden:

1. **Texto**: pegá tu link (en la app, Ajustes → Pantalla bloqueada → **Copiar mi link**).
2. **Obtener contenido de URL**: con el texto de arriba.
3. **Establecer fondo de pantalla**: elegí **Pantalla bloqueada** y desactivá **Mostrar previsualización**.

Para pasárselo a tus amigos: mantené apretado el atajo → **Compartir** → **Copiar enlace de iCloud**, y mandame ese link. Lo pongo en el botón **Instalar atajo** de la app. Al instalarlo, cada uno cambia el texto por su propio link.

## 2. Checklist

- [ ] Abrir el link en **Safari** → aparece el cartel "Instalá la app".
- [ ] Compartir → **Agregar a inicio** → se abre desde el ícono, a pantalla completa.
- [ ] La primera frase dice **🔥 Frase del día**.
- [ ] Deslizar hacia arriba pasa de frase y cada frase queda centrada.
- [ ] Doble toque → ❤️. Aparece en **Favoritos**.
- [ ] Mantener apretada una frase → menú **Marcar como Clave**.
- [ ] 📤 Compartir → se abre el menú de iOS con la imagen, mandala por WhatsApp.
- [ ] 🔄 cambia el fondo de esa frase.
- [ ] Temas → marcar **Gym** → el feed muestra frases de gym (cerrá y abrí la app).
- [ ] Temas → Visual → ⭐ en dos fondos + **Solo mis favoritos** → el feed rota entre esos.
- [ ] Ajustes → Notificaciones: poné 1 por día, **Desde** = la próxima hora en punto o cuarto (por ejemplo, 18:15) → activar → aceptar el permiso.
- [ ] Llega la notificación (hasta 15 minutos después de esa hora) y al tocarla abre la app en esa frase.
- [ ] Correr el atajo a mano → la pantalla bloqueada cambia y el reloj no tapa la frase.
- [ ] Probar los 3 estilos (Negro puro, Degradado oscuro, Foto oscurecida).
- [ ] Modo avión → la app sigue mostrando frases.
- [ ] Automatización: Atajos → Automatización → Hora del día 07:00 → Frase del día → **Ejecutar inmediatamente**.
